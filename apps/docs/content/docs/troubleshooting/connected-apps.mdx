## Connection completes but the app still shows disconnected

1. Return to Seira after the browser confirms success.
2. Open **Connected apps** and use **Refresh connection status**.
3. Check the **Connected** tab for the account, including its alias.
4. Retry from the original bot after the account appears active.

## The account is connected but the agent cannot use it

Start a new task after connecting the app so the engine receives a fresh tool catalog. Name the service and account explicitly in the request. If several accounts are connected, select or mention the intended alias.

Some engines expose connected tools differently. Verify the chosen engine supports MCP or the connected-tool bridge used by the app.

## The tool is missing or the bot says it is not allowed

Check the bot's tool grants. A bot with an assigned grant list only sees the tools granted to it — ungranted tools disappear from its catalog and calls to them are refused, by design. Open the bot's settings on the desktop, look under **Connected apps**, and either add the tool to the granted list or set the service back to all tools. Bots with no grant record at all keep every tool; phones show the current grants read-only under **App tools** in the bot's profile.

## Connected apps say the service is unavailable

This message appears only when a connected-apps service is in use. Check internet connectivity and try again later before reconnecting every account. The app keeps its installation identity through short outages. Deleting local credentials during an outage can separate existing grants from the installation. A Cloud and a self-hosted server keep trying on their own.

## Connected apps ask for a project key

The packaged desktop app and a self-hosted server installed from npm or Docker use Seira's connected-apps service. A Cloud and a source build use none unless `OMB_COMPOSIO_BROKER_URL` names one. `OMB_COMPOSIO_BROKER=off` turns the service off. Without a service, save your own Composio project key as described in [Self-hosted Composio](../connected-apps/self-hosted-composio.mdx).
