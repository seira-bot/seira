## Download a released build

Choose your computer below. Each link always downloads the latest published build.

| Platform | Recommended package | Notes |
|---|---|---|
| macOS | No download | [Run the server](/docs/self-hosting#on-your-own-computer-or-by-hand) with Node and open Seira in your browser, or [build Seira from source](#build-from-source). |
| Windows x64 | [Download installer](https://github.com/seira-bot/seira/releases/latest/download/Seira-setup.exe) | Per-user installer; Windows signing is not yet available. |
| Ubuntu 24.04 x64 | [Download `.deb`](https://github.com/seira-bot/seira/releases/latest/download/Seira-amd64.deb) · [AppImage](https://github.com/seira-bot/seira/releases/latest/download/Seira.AppImage) | The `.deb` is recommended; the AppImage is portable. |

<Callout type="warn" title="Windows SmartScreen">
  The Windows installer is not code-signed yet. Windows may show “Unknown publisher.” Verify that you downloaded it from the official Seira releases repository before choosing **More info → Run anyway**.
</Callout>

## Install an agent CLI

Seira needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart Seira.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Using Seira at work

If your company runs an Admin portal for Seira, you can sign in with your organization to use the AI models it provides, alongside your own. It is optional. See [Use Seira at work](./organisation.mdx).

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/seira-bot/seira.git
cd seira
corepack enable
pnpm install --frozen-lockfile
```

<Callout type="info" title="Windows">
  `corepack enable` writes to the Node.js install folder, so it fails with `EPERM` in a terminal without administrator rights. Run it in a terminal opened as administrator, or install pnpm with `npm install -g pnpm@10.33.0` and skip `corepack enable`.
</Callout>

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

<Callout type="info" title="macOS">
  There is no macOS download. The commands above run Seira on a Mac. To make your own app, run `pnpm package:mac`. It needs the Swift and Xcode command-line tools. A build that you make does not update itself. To update it, get the new code and build again.
</Callout>

## Where data lives

Seira stores its application data under `~/.seira`. Electron window and browser data use the normal per-platform application data directory.
